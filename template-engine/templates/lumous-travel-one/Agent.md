# Lumous Travel One Template Brief

## Purpose

`lumous-travel-one` is a single-page travel agency marketing template. It presents the agency, promotes destinations and packages, builds trust, and directs visitors to contact the business.

## Page sections

The landing page may contain these sections, in this order:

1. Navigation: logo and primary CTA only
2. Hero
3. About
4. Popular Destinations
5. Why Choose Us
6. Testimonials
7. Packages We Offer
8. Contact
9. Footer

No other pages or sections are currently part of this template.

## CTA behavior

The primary CTA should direct visitors to the Contact section by default. Its label and destination must be editable so the template owner can instead use an on-page section, external booking page, WhatsApp link, telephone link, or email link.

## Editable template controls

The template owner should be able to edit:

- Primary color
- Secondary color
- CTA labels and destinations
- Content displayed in each enabled section

Each section must have an independent visibility toggle so the template owner can decide whether it appears on the landing page:

- Show Navigation
- Show Hero
- Show About
- Show Popular Destinations
- Show Why Choose Us
- Show Testimonials
- Show Packages We Offer
- Show Contact
- Show Footer

Disabling a section should remove it from the rendered page without leaving empty spacing. The remaining enabled sections should preserve the order listed above.
